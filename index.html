How to play

Every bug left alive drains build health. Squash fast to grow your combo (up to ×5). At 0:20, Legacy Code shows up. Refactor it for a big bonus.

The bugs

  • Typo

    Common and slow. Squash on sight.

  • Null Pointer

    Darts, then freezes. Hit it mid-pause.

  • Race Condition

    Comes in pairs. Squash both fast for +50.

  • Heisenbug

    Vanishes when you look away.

  • Memory Leak

    Keeps growing. Takes three hits.

  • Legacy Code

    The boss. Shrugs off hits while deprecated.

  • Feature

    Not a bug! Let it ship for +50.

Power-ups

  • Coffee

    Slows every bug down for 4 seconds.

  • Linter

    Sweeps the file and squashes everything.

  • git revert

    Restores 30% build health.

  • Rubber Duck

    Lures bugs in and reveals Heisenbugs.

Keyboard: ← ↑ → ↓ aim, Space squash, P pause.
