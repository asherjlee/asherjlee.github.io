A 60-second sprint

Bug Bash

Squash bugs before they rot the build. Chain hits for a combo. Leave the gold stars alone: they're features.

How to play · 1 of 5

Ship the build

You have 60 seconds. Bugs crawl out of the code and drain build health. Squash them before the build hits 0%.

  • ComboSquash fast to chain hits, up to ×5 points.
  • MissesA tap on empty code resets your combo.
  • BonusBuild health left at the end becomes bonus points.

Know your bugs

  • Typo

    Common and slow. Squash on sight.

  • Null Pointer

    Darts, then freezes. Hit it mid-pause.

  • Race Condition

    Comes in pairs. Squash both fast for +50.

  • Heisenbug

    Vanishes when you look away.

  • Memory Leak

    Keeps growing. Takes three hits.

The boss, and a friend

  • Legacy Code

    The boss. Shows up at 0:20. Shrugs off hits while deprecated. Refactor it for a big bonus.

  • Feature

    Not a bug! Let it ship for +50. Squash it and you lose 150.

Grab power-ups

They pop up during the sprint. Tap one to use it.

  • Coffee

    Slows every bug down for 4 seconds.

  • Linter

    Sweeps the file and squashes everything.

  • git revert

    Restores 30% build health.

  • Rubber Duck

    Lures bugs in and reveals Heisenbugs.

Controls

  • TouchTap a bug to squash it.
  • MouseClick to squash.
  • Keyboard← ↑ → ↓ aim, Space squash, P pause

Your score goes on the leaderboard when the sprint ends. You can reopen this guide from the start screen or the ? button.
